# Kritika Jain — Portfolio

Full Stack Developer (MERN) portfolio built with Vite, React, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy (Vercel)

Import the repo on Vercel. Framework preset is Vite (build: `npm run build`, output: `dist`), configured in `vercel.json`.
